QED has classes just like many other languages so why aren't they part of the basic stuff? First, the way they are defined is different. Their functionality is expanded in some nifty way, as we'll see in this section.

There is no reserved keyword (like `class`) to declare a QED class. Classes in QED are defined just like functions, with a return type, a name and a set of parameters, using the same syntax. So how QED differs them from plain functions? By looking at the first letter; if the first letter is uppercase, we define a class. If lowercase, as specified before, we declare a function. As an aside, nouns are by convention used for classes whereas verbs are used for plain function names (of course, QED does not check this).

You may have plenty of questions at this point already, such as "Why a return type for classes?" Please bear with me and continue reading, it will all fall into place.
